# Q8C线性投影研究摘要

历史实验日期2026-10-13。本页记录与attention研究相关的独立投影实验；**本包不包含Q8C线性内核、原权重、capture或该基准runner**。下列数字摘自原报告，逐样本原数据没有随包提供，不是当前注意力库的性能结果。

## 设计与输入范围

同一RTX 4060 Laptop上保留原A，依次比较：B1宽向量读取＋寄存器转换＋col_major；B2再预计算groupsums；B3增加至N128/8warp。保持A16、group64、原Q8C参数及每输出的点积后反量化顺序。

B8真实capture是形状匹配的代理输入，并非每个投影实际的归一化中间激活。down输入由同一输入经原gate/up/SiLU产生；out缺少真实K6144输入而跳过。不能把这些代理输入结果当完整单层集成测量。

## 历史结果

8 warmup，正反扫各64样本，先数值资格后计时。B2端到端包含groupsums，不能只比较linear子核。

| 投影 | A正扫p50 | B2端到端正扫p50 | 时间比 |
| --- | ---: | ---: | ---: |
| input，N14336/K5120 | 1.4746ms | 0.6400ms | 2.30倍 |
| gate，N17408/K5120 | 1.6210ms | 0.7094ms | 2.29倍 |
| up，N17408/K5120 | 1.6200ms | 0.7085ms | 2.29倍 |
| down，N5120/K17408 | 1.8697ms | 0.8515ms | 2.20倍 |

原报告记录了四个投影B1–B3对A逐字节相同、finite和重复确定性通过；B3在这些shape上慢于B2约7–13%，未采用。两次先行运行分别因心跳共享冲突、prepared-down字段问题中断，最终数字只来自修复后的完成轮。

## 解释与限制

同权重字节的纯流读probe约209–264GB/s，而gate线性核codes/time由A约55GB/s提高到B2约135GB/s。结合受控改动，这支持访存/转换/重复sums路径存在优化空间；无硬件计数器时，不能精确分解DRAM、指令、同步或占用的贡献，probe也不是完整矩阵核可直接达到的时间。

把投影比率外推到原五层组件，曾估算总计算40.27ms降至约18.3ms。**这是推算，out亦用了未测假设，不是整层实测。** 对照Mac五层4.08ms仍不支持在该配置下为了速度扩大完整层迁移，但不构成其他硬件、批量或内存目标的普遍结论。

进一步需要真实中间激活、单层生命周期与通信测量。公开包的现有数据索引见[provenance](provenance.md)，完整原线性实验不能仅凭此包复现。
